<SlideHeader title="O que é um Computador?" subtitle="Máquina Eletrônica e Processador de Dados" />

<div class="grid grid-cols-1 gap-3 items-stretch mt-1 compact-code">

<InfoCard title="💻 Conceito & Funcionamento" variant="blue">

- Definição: "Um computador digital é uma máquina que pode resolver problemas executando instruções que lhe são fornecidas. Uma sequência de instruções descrevendo como executar uma determinada tarefa é chamada de programa. Os circuitos eletrônicos de cada computador podem reconhecer e executar diretamente um conjunto limitado de instruções simples, nas quais todos os programas devem ser convertidos antes de poderem ser executados." (TANENBAUM; AUSTIN, 2013, p. 1).
- Origem do Termo: Deriva do latim computare ("calcular", "reunir contas"), tendo como substantivo de agente computator ("aquele que calcula"). Historicamente e conceitualmente, a máquina também é classificada como um sistema de processamento de dados.

</InfoCard>

Estado “0”: Representa a desativação (desligamento) de um recurso ou circuito interno.


Base da Máquina: Possibilita representar dados do mundo exterior e estabelece as bases de funcionamento do sistema.

</InfoCard>

<SlideHeader title="Representação de Dados e O Byte" subtitle="A Transição do Bit ao Byte e a Capacidade da Tabela ASCII" />

<div class="grid grid-cols-3 gap-3 items-stretch mt-1 compact-code">

<InfoCard title="🧠 Conceito de Byte (Octeto)" variant="blue">

O Octeto de Bits: A representação de um dado externo na memória utiliza um conjunto de oito bits, chamado em inglês de byte.


Representação de Caractere: Cada byte possui a capacidade de representar um caractere individual qualquer.


Estrutura Interna: Serve como a unidade fundamental para estruturação da informação processada.

</InfoCard>

<InfoCard title="📌 Capacidade e Tabela ASCII" variant="teal">

Base Binária (2): O valor numérico 2 refere-se à base de operação interna do sistema eletrônico (o bit).


Cálculo de Combinações (2⁸): Elevando a base 2 ao expoente 8 (bits do byte), obtém-se o total de 256 combinações.


Limite de Caracteres: Define o limite máximo de 256 caracteres utilizáveis, padronizados na tabela ASCII.

</InfoCard>

<InfoCard title="" variant="amber">

| 1 Byte = 8 Bits | 2⁸ = 256 Caracteres Possíveis (Padrão ASCII) |

</InfoCard>

</div>
<div class="senai-footer-tip">Nota: ASCII é o acrônimo de American Standard Code for Information Interchange (Código Padrão Americano para o Intercâmbio de Informação).</div>

<InfoCard title="📌 Cálculo de Combinações (2⁸)" variant="blue">

<SlideHeader title="O Sistema Binário e o Mecanismo Posicional" subtitle="Como as potências de base 2 determinam o valor de cada bit" />

<div class="grid grid-cols-3 gap-3 items-stretch mt-1 compact-code">

<InfoCard title="🔌 Pesos Posicionais em Base 2 (1 Byte)" variant="blue">

Estrutura Posicional: Assim como a base 10 utiliza potências de 10 (1, 10, 100), o sistema binário baseia-se em potências de base 2.


Pesos de 8 Bits (da direita para esquerda):

- 2⁷ = 128 • 2⁶ = 64 • 2⁵ = 32 • 2⁴ = 16
- 2³ = 8 • 2² = 4 • 2¹ = 2 • 2⁰ = 1

Regra Operacional: Bit 1 ativa e soma o peso da potência correspondente; Bit 0 anula o peso.

</InfoCard>

<InfoCard title="🧮 Exemplo de Cálculo 1: Binário 1101₂ (4 bits)" variant="teal">

Alinhamento Posicional e Multiplicação:

- Posição 3 (2³ = 8): 1 × 8 = 8
- Posição 2 (2² = 4): 1 × 4 = 4
- Posição 1 (2¹ = 2): 0 × 2 = 0 (anulado)
- Posição 0 (2⁰ = 1): 1 × 1 = 1

Soma dos Pesos Ativos:


8 + 4 + 0 + 1 = 13₁₀


Resultado: O binário (1101)₂ equivale a (13)₁₀ em decimal.

</InfoCard>

<InfoCard title="" variant="amber">

Fórmula Geral: Valor Decimal = Σ (Bit × 2^Posição) — Somam-se apenas as potências com bit 1

</InfoCard>

</div>

<SlideHeader title="Conversão Binário para Decimal: Passo a Passo" subtitle="Método prático de decomposição com números de 5 e 6 bits" />

<div class="grid grid-cols-3 gap-3 items-stretch mt-1 compact-code">

<InfoCard title="🔟 Exemplo de Cálculo 2: Binário 10110₂ (5 bits)" variant="blue">

Mapeamento das Potências de 2:

- Posição 4 (2⁴ = 16): Bit 1 ➔ 16
- Posição 3 (2³ = 8): Bit 0 ➔ 0
- Posição 2 (2² = 4): Bit 1 ➔ 4
- Posição 1 (2¹ = 2): Bit 1 ➔ 2
- Posição 0 (2⁰ = 1): Bit 0 ➔ 0

Operação de Adição:


16 + 0 + 4 + 2 + 0 = 22₁₀


Resultado: (10110)₂ = (22)₁₀

</InfoCard>

<InfoCard title="📊 Exemplo de Cálculo 3: Binário 101101₂ (6 bits)" variant="teal">

Mapeamento das Potências de 2:

- Posição 5 (2⁵ = 32): Bit 1 ➔ 32
- Posição 4 (2⁴ = 16): Bit 0 ➔ 0
- Posição 3 (2³ = 8): Bit 1 ➔ 8
- Posição 2 (2² = 4): Bit 1 ➔ 4
- Posição 1 (2¹ = 2): Bit 0 ➔ 0
- Posição 0 (2⁰ = 1): Bit 1 ➔ 1

Operação de Adição:


32 + 8 + 4 + 1 = 45₁₀


Resultado: (101101)₂ = (45)₁₀

</InfoCard>

<InfoCard title="" variant="amber">

<SlideHeader title="Cálculos com 1 Byte Completo (8 Bits) e ASCII" subtitle="Como o computador calcula caracteres do teclado a partir de pulsos elétricos" />

<div class="grid grid-cols-3 gap-3 items-stretch mt-1 compact-code">

<InfoCard title="💻 Exemplo de Cálculo 4: Letra 'A' (01000001₂)" variant="blue">

Grade de 8 Bits e Pesos Posicionais:


[128:0] [64:1] [32:0] [16:0] [8:0] [4:0] [2:0] [1:1]


Decomposição Matemática:


(0×128) + (1×64) + (0×32) + (0×16) + (0×8) + (0×4) + (0×2) + (1×1)


Soma dos Termos Ativos: 64 + 1 = 65₁₀


Conexão ASCII: Decimal 65 = Letra maiúscula 'A'

</InfoCard>

<InfoCard title="⌨️ Exemplo de Cálculo 5: Símbolo '@' (01000000₂)" variant="teal">

Grade de 8 Bits e Pesos Posicionais:


[128:0] [64:1] [32:0] [16:0] [8:0] [4:0] [2:0] [1:0]


Decomposição Matemática:

- Apenas o bit da posição 6 (2⁶ = 64) é igual a 1;

todos os outros 7 bits são iguais a 0.


Soma dos Termos Ativos: 64 = 64₁₀


Conexão ASCII: Código decimal 64 = Símbolo '@'

</InfoCard>

<InfoCard title="" variant="amber">

Todo caractere pressionado no teclado vira um byte de 8 bits cujo cálculo decimal define o símbolo.

</InfoCard>

</div>

<SlideHeader title="Cálculos com Valores Altos: Limites de 1 Byte" subtitle="Demonstração de cálculos com MSB ativo e capacidade máxima (255)" />

<div class="grid grid-cols-3 gap-3 items-stretch mt-1 compact-code">

<InfoCard title="⚡ Exemplo de Cálculo 6: Binário 11001010₂ (202)" variant="blue">

Grade de Bits com MSB (128) Ativo:

- Bit 7 (2⁷ = 128): Bit 1 ➔ 128
- Bit 6 (2⁶ = 64): Bit 1 ➔ 64
- Bit 3 (2³ = 8): Bit 1 ➔ 8
- Bit 1 (2¹ = 2): Bit 1 ➔ 2
- Posições 5, 4, 2, 0: Bit 0 ➔ 0

Operação de Adição:


128 + 64 + 8 + 2 = 202₁₀


Resultado: (11001010)₂ = (202)₁₀

</InfoCard>

<InfoCard title="♾️ Exemplo de Cálculo 7: Byte Máximo 11111111₂ (255)" variant="teal">

Soma Completa de Todos os 8 Bits Ativos:


128 + 64 + 32 + 16 + 8 + 4 + 2 + 1

- 128 + 64 = 192 ➔ +32 = 224 ➔ +16 = 240
- +8 = 248 ➔ +4 = 252 ➔ +2 = 254 ➔ +1 = 255₁₀

Propriedade Notável: 2⁸ - 1 = 256 - 1 = 255₁₀


Resultado: (11111111)₂ = (255)₁₀

</InfoCard>

<InfoCard title="" variant="amber">

Intervalo de 1 Byte sem sinal: 00000000₂ (0) a 11111111₂ (255) — Exatamente 256 valores possíveis!

</InfoCard>

<SlideHeader title="Atalhos Mentais de Cálculo & Exercícios Resolvidos" subtitle="Técnicas rápidas para conferência e fixação imediata do conteúdo" />

<div class="grid grid-cols-3 gap-3 items-stretch mt-1 compact-code">

<InfoCard title="💡 3 Atalhos Mentais para Acelerar Cálculos" variant="blue">

1. Regra da Paridade (Bit LSB):

- Se o bit 0 (peso 1) for 0 ➔ Número PAR (ex: 1100₂ = 12₁₀)
- Se o bit 0 for 1 ➔ Número ÍMPAR (ex: 1101₂ = 13₁₀)

2. Cadeia de 1s Consecutivos da Direita:

- Vale a próxima potência menos 1 (ex: 111₂ = 8 - 1 = 7; 1111₂ = 16 - 1 = 15)

3. Potência Única Isolada:

- Se há apenas um bit 1, o valor é o peso direto (ex: 00100000₂ = 32₁₀)

</InfoCard>

<InfoCard title="❓ Desafios de Fixação com Soluções" variant="teal">

Exercício A: Converta (00010101)₂ para decimal.

- Cálculo: 16 + 4 + 1 = 21₁₀

Exercício B: Converta (00110000)₂ para decimal.

- Cálculo: 32 + 16 = 48₁₀ (Caractere '0' na ASCII)

Exercício C: Converta (01111111)₂ para decimal.

- Cálculo: 64 + 32 + 16 + 8 + 4 + 2 + 1 = 128 - 1 = 127₁₀ (ASCII 7 bits)

</InfoCard>

<InfoCard title="" variant="amber">

Com a régua dos pesos (128, 64, 32, 16, 8, 4, 2, 1), qualquer conversão é resolvida em segundos!

</InfoCard>

Impacto: Base para a lógica bivalente e sistemas computacionais binários.

<div class="grid grid-cols-1 gap-3 items-stretch mt-1 compact-code">

<InfoCard title="Para nomear variáveis, regras estritas devem ser seguidas:" variant="blue">

Primeiro Caractere: Deve ser obrigatoriamente alfabético, não numérico ou símbolo.


Nomes Compostos: Não podem conter espaços em branco, utilizando-se o underline (_) para separação (ex: NOME_USUÁRIO).


Palavras Reservadas: Termos da linguagem (como INTEIRO, REAL, LEIA) não podem ser usadas como nomes.

Representada pelo comando 'const', é associada a um rótulo de identificação e um valor que não sofre variações, independentemente das operações realizadas.


Um exemplo clássico é a constante matemática PI (3.14159265).


As regras de nomenclatura para constantes são as mesmas aplicadas às variáveis.

- Exemplo: Se X ← 5, a expressão -X resulta em -5.

<SlideHeader title="Desvio Condicional Simples: Se ... Então" subtitle="A Introdução do Losango de Decisão da ISO 5807 (Seção 4.3)" />

<div class="grid grid-cols-2 gap-3 items-stretch mt-1 compact-code">

<InfoCard title="Conceito e Diagrama de Blocos" variant="blue">

- Executa um bloco de instruções APENAS se a condição for VERDADEIRA.
- Se a condição for FALSA, o bloco é simplesmente ignorado e o fluxo segue adiante.
- No diagrama de blocos, o losango de decisão deriva duas saídas: SIM (desvio) e NÃO (continuidade).

</InfoCard>

<InfoCard title="Exemplo em Português Estruturado" variant="teal">

```text
se (MEDIA >= 7.0) entao
    escreva('Aluno Aprovado!')
```


fim_se


*Caso a média seja inferior a 7.0, o programa não faz nada e segue diretamente para a próxima instrução.*

</InfoCard>

</div>
<div class="senai-footer-tip">Na decisão simples existe apenas a cláusula ENTAO; a cláusula SENAO não está presente.</div>

<SlideHeader title="Capítulo 5 ■ Repetições: O Comando while" subtitle="Executando Tarefas Repetitivas com Avaliação Pré-Teste" />

<div class="grid grid-cols-2 gap-3 items-stretch mt-1 compact-code">

<InfoCard title="A Estrutura do while" variant="blue">

- O while repete a execução de um bloco enquanto a condição for True.
- A condição é testada ANTES de cada repetição (pré-teste).
- Se a condição for falsa no primeiro teste, o bloco nunca é executado.

```python
while <condicao>:
    bloco_a_ser_repetido
```

</InfoCard>

<InfoCard title="O Perigo do Loop Infinito" variant="teal">

- Um loop infinito ocorre quando a condição NUNCA se torna False.
- O programa trava e consome 100% da CPU.

Exemplo de loop correto com contador:


```python
x = 1
while x <= 5:
    print(x)
    x = x + 1  # Incremento vital de parada!
```

</InfoCard>

</div>
<div class="senai-footer-tip">Regra de ouro: Todo laço while precisa de uma instrução interna que altere a condição de teste.</div>

<SlideHeader title="Contadores vs. Acumuladores em Repetições" subtitle="As Duas Técnicas Fundamentais de Rastreamento de Dados em Laços" />

<div class="grid grid-cols-2 gap-3 items-stretch mt-1 compact-code">

<InfoCard title="Contador (Incremento Fixo)" variant="blue">

- Soma um valor constante (geralmente +1) a cada iteração.
- Serve para controlar quantas vezes o laço rodou.

```python
tabuada = int(input("Tabuada de: "))
x = 1
while x <= 10:
    print(f"{tabuada} x {x} = {tabuada * x}")

- Serve para totalizadores, saldos e médias.

soma = 0  # inicialização
n = 1
while n <= 5:

    soma = soma + valor  # acumulador
    n = n + 1
print("Total acumulado:", soma)
```

</InfoCard>

<InfoCard title="print() vs. return (Diferença Crucial)" variant="teal">

- print(): Apenas exibe o valor na tela para o ser humano ler. O valor não pode ser reaproveitado em cálculos!
- return: Envia o resultado de volta para quem chamou a função, permitindo armazenar em variáveis e combinar operações:

```python
maior = maximo(10, 25)
resultado = maior * 2  # 50
```

</InfoCard>

<SlideHeader title="Escopo, Parâmetros Opcionais e Recursividade" subtitle="Recursos Profissionais de Arquitetura de Funções no Python" />

<div class="grid grid-cols-2 gap-3 items-stretch mt-1 compact-code">

<InfoCard title="Escopo Local vs. Escopo Global" variant="blue">

- Variáveis criadas dentro da função pertencem ao Escopo Local e desaparecem quando a função termina.
- Variáveis criadas fora pertencem ao Escopo Global.
- Parâmetros com valor padrão (opcionais):

```python
  def barra(tamanho=40, char="-"):
      print(char * tamanho)
  barra()        # 40 traços
  barra(20, "*") # 20 asteriscos
```

</InfoCard>

<InfoCard title="Recursividade: A Função que Chama a Si Mesma" variant="teal">

Uma função é recursiva quando invoca a si mesma até atingir uma condição de parada (caso-base).


Exemplo clássico do Fatorial:


```python
def fatorial(n):
    if n <= 1:
        return 1  # Caso-base
    return n * fatorial(n - 1)
```


*fatorial(4) = 4 * 3 * 2 * 1 = 24*

</InfoCard>

</div>
<div class="senai-footer-tip">A recursividade substitui laços matemáticos complexos através de elegantes definições indutivas.</div>

<SlideHeader title="Capítulo 9 ■ Manipulação de Arquivos e Persistência em Disco" subtitle="Salva, Lê e Processa Dados de Forma Durável no Sistema Operacional" />

<div class="grid grid-cols-2 gap-3 items-stretch mt-1 compact-code">

<InfoCard title="Modos de Abertura com open()" variant="blue">

- "r" (read): Abre apenas para leitura (erro se não existir).
- "w" (write): Abre para escrita (CRIA ou SOBREESCREVE o arquivo!).
- "a" (append): Abre para anexar no final (preserva o conteúdo anterior).

```python
# Forma moderna e segura com gerenciador de contexto (with):
with open("dados.txt", "w", encoding="utf-8") as f:
    f.write("Primeira linha gravada\n")
    f.write("Segunda linha gravada\n")
```

</InfoCard>

<InfoCard title="Leitura Linha a Linha & Boas Práticas" variant="teal">

- O comando with garante que o arquivo seja fechado automaticamente, mesmo se ocorrer um erro durante a execução.

```python
# Lendo linha por linha de forma eficiente na memória:
with open("dados.txt", "r", encoding="utf-8") as f:
    for linha in f:
        print(linha.strip())  # strip() remove o \n extra
```


*Permite processar arquivos gigantescos de logs sem sobrecarregar a memória RAM.*

</InfoCard>

</div>
<div class="senai-footer-tip">A instrução with open(...) elimina vazamentos de memória e arquivos bloqueados no sistema operacional.</div>

<SlideHeader title="Capítulo 10 ■ Programação Orientada a Objetos: Classes e Objetos" subtitle="Modelando Entidades do Mundo Real através de Atributos e Comportamentos" />

<div class="grid grid-cols-2 gap-3 items-stretch mt-1 compact-code">

<InfoCard title="Classe (O Molde) vs. Objeto (A Instância)" variant="blue">

- Classe: É a planta baixa ou a receita que define o formato (ex: molde de carro).
- Objeto: É a entidade real concretizada na memória (ex: o carro com placa e cor).

O método construtor __init__:


```python
class Conta:
    def __init__(self, titular, saldo_inicial):
        self.titular = titular  # atributo
        self.saldo = saldo_inicial
```

</InfoCard>

<InfoCard title="Métodos e o Parâmetro self" variant="teal">

- Métodos são funções que pertencem à classe e operam sobre os dados do próprio objeto via self:

```python
    def depositar(self, valor):
        self.saldo += valor
```


```python
    def sacar(self, valor):
        if self.saldo >= valor:
            self.saldo -= valor
            return True
        return False
```

</InfoCard>

<div class="senai-footer-tip">POO une dados (atributos) e ações (métodos) na mesma estrutura protegida.</div>

<SlideHeader title="Herança e Polimorfismo na POO" subtitle="Reutilizando e Especializando Classes Existentes sem Duplicação de Código" />

<div class="grid grid-cols-2 gap-3 items-stretch mt-1 compact-code">

<InfoCard title="O Conceito de Herança" variant="blue">

- Permite que uma nova classe (subclasse) herde todos os atributos e métodos de uma classe pai (superclasse).

```python
class ContaEspecial(Conta):
    def __init__(self, titular, saldo, limite):
        super().__init__(titular, saldo)
        self.limite = limite
```


*A ContaEspecial já nasce sabendo depositar e consultar saldo!*

</InfoCard>

<InfoCard title="Polimorfismo e Sobrescrita (Override)" variant="teal">

- Polimorfismo: Capacidade de tratar objetos de tipos diferentes com a mesma interface.
- Sobrescrita: A subclasse pode redefinir o comportamento de um método herdado para atender sua regra de negócio:

```python
    def sacar(self, valor):
        if (self.saldo + self.limite) >= valor:
            self.saldo -= valor
            return True
        return False
```

</InfoCard>

</div>
<div class="senai-footer-tip">Com Herança e Polimorfismo você escreve sistemas corporativos escaláveis e fáceis de estender.</div>

# Criação da tabela e inserção com parâmetros seguros (?):
